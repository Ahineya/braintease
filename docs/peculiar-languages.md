# Peculiar Programming Languages Worth Exploring

1. **Kernel** — First-class evaluation semantics; operatives instead of special forms.
   https://web.cs.wpi.edu/~jshutt/kernel.html

2. **REBOL** — Code as data; effortlessly create domain-specific languages.
   https://www.rebol.com/

3. **Egison** — Programmable pattern matching over sets, multisets, and other structures.
   https://www.egison.org/

4. **Refal** — Soviet symbolic rewriting language from the 1960s.
   https://www.refal.net/

5. **Icon** — Goal-directed evaluation, generators, and automatic backtracking.
   https://www2.cs.arizona.edu/icon/

6. **Factor** — Concatenative, stack-based language with an optimizing compiler.
   https://factorcode.org/

7. **Joy** — Pure concatenative programming; composition replaces function application.
   https://hypercubed.github.io/joy/html/j00ovr.html

8. **E** — Object-capability security, promises, and asynchronous distributed computing.
   https://www.erights.org/

9. **Oz** — Dataflow concurrency, logic variables, constraints, and multiparadigm programming.
   https://mozart2.org/

10. **Uxn / Uxntal** — Minimal 8/16-bit stack VM with its own tiny computing ecosystem.
    https://wiki.xxiivv.com/site/uxn.html

11. **Self** — Prototype-based OOP without classes; live object-oriented environment.
    https://selflanguage.org/

12. **SNOBOL4** — Pattern matching as a fundamental computational mechanism.
    https://www.snobol4.org/

13. **PicoLisp** — Radical Lisp minimalism; tiny interpreter and uniform data model.
    https://picolisp.com/

14. **Uiua** — Tacit, stack-based array programming with higher-order modifiers.
    https://www.uiua.org/

15. **Tcl** — Everything is a command; extensible control structures and embeddable scripting.
    https://www.tcl-lang.org/
