Explore the Ripple computer architecture through RVM. Run Riplix, use its Unix shell, and launch a graphical desktop — all on a virtual CPU running locally in your browser.

Run shutdown, then export the disk to keep your files. Import a saved .img disk to continue later (up to 256 MiB). Reset starts over with a fresh disk.

About Ripple and RVM

Ripple is the computer architecture. RVM is its virtual machine: it executes Ripple instructions and provides the memory and devices that let a complete operating system run. Here, RVM runs as WebAssembly inside your browser.

Riplix, derived from FUZIX, provides the Unix environment. Nano-X, NanoWM, and NXDSKTOP provide the graphical desktop. The operating system and its applications execute on the virtual Ripple CPU.
