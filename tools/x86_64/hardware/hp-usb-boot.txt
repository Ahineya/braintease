What this build does
--------------------
- After firmware handoff, check DMAR/MCFG and PCIe DMA capabilities BEFORE
  enabling this controller's bus mastering. Require VT-d translation/protected
  memory off on every DRHD; never change firmware IOMMU mappings. Reject
  unsupported IOMMU/ATS/PRI/PASID states and reserved-RMRR overlap.
- Initialize NVMe with coherent, ordered native buffers, masked interrupts and
  polling. Namespace Write/Flush/Format and other unsafe admin commands are
  refused at the final command-submission boundary. Storage selfcheck writes
  are not compiled into this build. It is not a persistent filesystem build.
- Read Identify, protective MBR, both GPT headers and both entry arrays. Check
  CRCs, reciprocal headers, matching arrays, unique partition GUIDs and ranges.
  No partition is selected, mounted, resized or repaired. No ext4 payload is read.
- Print model/capacity/partition LBAs. Disable the controller and bus mastering
  after reads; then run Riplix's shell from the embedded RAM root. Session file
  changes still reset at reboot. The fixed status header retains the result.

Implemented platform prerequisites
----------------------------------
- Native 64-bit GOP mapping through the checked device mapper. Visible span,
  stride, dimensions, format, physical address width and canonical bounds are
  checked. Only RGB/BGR 32-bit formats are supported; mapping is conservatively
  uncached. Physical RAM allocation remains bounded to 64 GiB, independently
  of device addresses. C16 cells, pointers, banks and heap ABI are unchanged.
- UEFI RSDP handoff; checksummed, bounded XSDT/RSDT and MADT/FADT discovery.
  ACPI tables must remain in firmware-reserved ACPI memory below 64 GiB.
  MADT type-0 and type-9 enabled CPUs, I/O APICs, address override and ISA
  overrides are parsed. Other bounded records, including NMI records, are
  skipped. The actual HP MADT passes the production parser harness.
- Boot-CPU local APIC initialization: x2APIC when supported, otherwise xAPIC.
  I/O APIC lines, LINT/NMI inputs and unused LVT sources are masked. Periodic
  local timer calibrated against TSC, about 100 Hz; no HPET dependency.
  Counter-only ISR, IST2, GPR/x87/SSE preservation and safe C16 checkpoints
  remain. No AML/SCI, SMP, power management or external-device routing yet.
- Loader carries and verifies an explicit PE base relocation. Early loader
  errors use UEFI text while services remain valid; initialized-kernel errors
  and exceptions reach the framebuffer. No text protocol is used after the
  first ExitBootServices attempt. Absent COM1 returning 0xff is not input.
