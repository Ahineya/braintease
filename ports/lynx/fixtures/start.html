Welcome to Lynx

A text browser running inside FUZIX or Fuse-X. HTTP, HTTPS and DNS use the guest's own networking stack.

  • Example domain

Keys

Up/Down or Tab   Select a link or form field
Right or Enter   Follow a link / submit a form
Left             Back
Space / b        Next / previous page
g                Open a URL (Ctrl-U clears the field)
z                Cancel a transfer
Ctrl-L           Redraw
q, then y        Quit

This build supports verified HTTPS, HTTP, ASCII and Latin-1 input with ASCII display. JavaScript and compressed responses are not supported. Some sites require those features.

Transfers are limited to 64 KiB including HTTP headers and chunk framing. Two rendered pages are cached by default. Settings live in /etc/lynx.cfg.
