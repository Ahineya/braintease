# Nano-X adaptation baseline

Pinned Microwindows/Nano-X sources for the FUZIX graphics effort. The server is
not yet ported, built or installed. Start with the [audit](../../docs/graphics/nanox-audit.md),
[architecture](../../docs/graphics/architecture.md), and [milestones](../../docs/graphics/roadmap.md).

[UPSTREAM.md](UPSTREAM.md) records the revision, archive checksum, licenses and
verification commands. Keep `upstream/` pristine; place future source adaptations
in an explicit patch layer and platform adapters alongside it.
