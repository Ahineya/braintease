Welcome to rOS!

Try these commands:
  DIR              List files on this disk.
  HELLO            Run the hello-world program.
  SIERP            Draw a Sierpinski triangle.
  BF               Run the one-line Brainfuck interpreter.
  TYPE README.TXT  Display this text file again.
  EXIT             Stop rOS.

At the BF prompt, enter this program to print A:
++++++++[>++++++++<-]>+.

Programs return to the shell when they finish.
